Foundations

Ahremark builds tudo sobre baseline grid de 1rem. Toda altura, padding, line-height alinha rows. Resultado: ritmo vertical perfeito sem esforço.

(08)

Scroll choreography

Truque-mestre Ahremark: footer sticky com bottom: 0, z-index: 0. Main content rola por cima. Próximo case é revelado dentro do footer conforme scroll chega ao fim. Hover intensifica media opacity 0.7 → 1.

CSS pattern

.l-site-footer {
  position: sticky;
  bottom: 0;
  left: 0;
  width: 100%;
  z-index: 0;
  background: var(--color-gray-4);  /* dark */
  color: var(--color-white);
  clip-path: inset(0);
}

.main-content {
  position: relative;
  z-index: 1;
  background: var(--color-background);
}

.l-site-footer__media {
  position: absolute;
  inset: 0;
  opacity: 0.7;
  transition: opacity 0.5s linear;
}
.l-site-footer:hover .l-site-footer__media { opacity: 1; }

.l-site-footer--case .l-site-footer__column--title {
  padding-bottom: 50vh;  /* makes next-case title space generously */
}
