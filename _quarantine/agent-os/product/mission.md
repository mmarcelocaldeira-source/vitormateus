# Product Mission

## Problem

Photographers need a portfolio that loads fast, looks distinctive, and showcases their work without the overhead of a CMS platform or heavy frontend framework.

## Target Users

Two equal audiences:
- **Potential clients** — architects, restaurants, brands discovering Vitor's work and deciding to hire him
- **Vitor Mateus** — managing and updating his own projects without developer involvement

## Solution

Pure static HTML/CSS/JS — no build step, no framework, no runtime dependencies. Fast by default. Deployable anywhere. Custom design system built around photography, not around a UI library.
